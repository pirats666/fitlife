# Уровни доказательности

A — систематические обзоры/мета-анализы и качественные position stands по релевантному вопросу.

B — качественные контролируемые исследования и последовательные данные.

C — ограниченные исследования, наблюдательные данные или косвенные данные.

D — практическое экспертное мнение/гипотеза.

В базе всегда отделять данные исследования от тренерской интерпретации. Для важных правил хранить references и дату проверки.
