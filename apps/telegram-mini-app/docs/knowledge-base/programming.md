# Программирование

## Основные переменные
- частота;
- объём;
- интенсивность;
- диапазон повторений;
- отдых;
- темп;
- близость к отказу;
- выбор упражнений;
- порядок упражнений;
- прогрессия.

## Модели
- full body;
- upper/lower;
- split;
- смешанные схемы.

Выбор определяется целью, опытом, доступным временем, восстановлением, оборудованием и предпочтениями.

## Прогрессия
Использовать заранее определённое правило: например, постепенное увеличение повторений в заданном диапазоне с последующим увеличением нагрузки. Не увеличивать одновременно все переменные без необходимости.

## Контроль
Хранить историю тренировок и основание изменения программы.
