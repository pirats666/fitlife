# Кинезиология

Кинезиология рассматривает движение человека и взаимодействие сегментов тела.

## Паттерны
- squat
- hinge
- lunge
- horizontal push
- vertical push
- horizontal pull
- vertical pull
- carry
- rotation
- anti-rotation
- locomotion

## Анализ
Для упражнения фиксировать суставные действия, направление движения, плоскость, внешнюю нагрузку, точки опоры, стабильность и требуемый контроль.

## Регрессия
Уменьшить сложность, диапазон, нагрузку или координационные требования.

## Прогрессия
Увеличить нагрузку, объём, сложность, ROM или требования к контролю только при сохранении подходящего качества выполнения.
