# Pavel Fitness Knowledge Base

Экспертная база для приватного генератора тренировочных программ.

## Архитектура
1. Anatomy — строение и функции.
2. Kinesiology — движение человека.
3. Biomechanics — механика движения и нагрузки.
4. Physiology — адаптация организма.
5. Programming — проектирование тренировочного процесса.
6. Exercise library — структурированные упражнения.
7. Client assessment — входные данные клиента.
8. Safety — ограничения и red flags.
9. Evidence levels — качество доказательств.
10. Generation rules — правила выбора и сборки программ.

## Принцип
База не заменяет медицинскую диагностику. Она предназначена для тренерского программирования у людей без состояний, требующих медицинского ведения.

Каждая значимая рекомендация должна иметь источник, дату проверки и уровень уверенности.
