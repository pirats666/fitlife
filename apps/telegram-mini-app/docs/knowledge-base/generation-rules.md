# Правила генерации

## Pipeline
1. Получить профиль клиента.
2. Проверить безопасность и ограничения.
3. Определить основную цель и приоритеты.
4. Определить доступные дни, длительность, место и оборудование.
5. Выбрать структуру программы.
6. Распределить базовые паттерны движений.
7. Подобрать упражнения из Exercise Library.
8. Назначить объём, интенсивность и отдых.
9. Добавить понятное правило прогрессии.
10. Проверить баланс программы и конфликт ограничений.
11. Сформировать черновик с rationale.
12. Сохранить программу как версию.

## Правила выбора
- Сначала безопасность и ограничения, затем цель, затем удобство выполнения.
- Не добавлять оборудование, которого нет у клиента.
- Учитывать доступную длительность занятия.
- Для новичка начинать с простых вариантов движений и умеренного объёма.
- При нескольких ограничениях выбирать упражнения, удовлетворяющие всем известным ограничениям, либо помечать конфликт для ручного решения тренером.
- Не выбирать упражнение только потому, что оно сильнее нагружает отдельную мышцу: учитывать движение, технику, оборудование и место тренировки.
- Каждая программа должна содержать объяснимую причину выбора ключевых упражнений.

## Прогрессия
- Предпочтительно изменять один главный параметр за раз: повторения, подходы, нагрузку, сложность или плотность.
- Прогрессия должна соответствовать уровню клиента и переносимости текущего объёма.
- Если качество техники ухудшается, прогрессию не ускорять.
- Не считать боль обязательным критерием эффективности.

## Проверка перед сохранением
- Все упражнения существуют в библиотеке или явно помечены как требующие проверки.
- Оборудование соответствует профилю.
- Количество тренировочных дней соответствует запросу.
- Есть баланс основных двигательных паттернов.
- Нет явного конфликта с указанными ограничениями.
- Есть правило прогрессии.
- Rationale объясняет ключевые решения.

## Запреты
- не диагностировать;
- не назначать лечение;
- не использовать одно универсальное правило для всех;
- не использовать боль как цель тренировки;
- не подменять источник уверенным утверждением;
- при недостатке данных не выдавать предположение за факт.
