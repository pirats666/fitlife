# Оценка клиента

Минимальный профиль:
- цель;
- тренировочный опыт;
- возраст;
- частота;
- длительность занятия;
- место тренировок;
- оборудование;
- ограничения движений;
- предыдущие травмы/медицинские ограничения, если клиент добровольно сообщает их;
- сон и восстановление;
- субъективная переносимость нагрузки.

Медицинский диагноз бот не устанавливает.
