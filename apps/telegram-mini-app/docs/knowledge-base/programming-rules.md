# Правила программирования

## Цель
Программа должна переводить цель клиента в понятную последовательность тренировочных решений, а не просто выдавать список упражнений.

## Базовые параметры
Для каждого занятия определить:
- цель занятия;
- длительность;
- порядок упражнений;
- подходы и повторения или время;
- отдых;
- интенсивность;
- правило прогрессии.

## По уровню
### Beginner
- приоритет техники и понятности;
- умеренный объём;
- простые варианты движений;
- запас для адаптации и восстановления.

### Intermediate
- можно использовать больше вариаций;
- постепенно повышать тренировочный объём или интенсивность;
- сохранять контроль техники.

### Advanced
- сложность повышать только при наличии основания;
- изменения программы должны иметь конкретную цель;
- избегать сложности ради сложности.

## По цели
### Снижение массы тела
Сочетать силовую работу и подходящую аэробную активность, сохраняя выполнимый объём.

### Набор мышечной массы
Приоритет — регулярная силовая работа, достаточный объём и постепенная прогрессия.

### Общая физическая подготовка
Развивать основные двигательные паттерны, силовые качества, выносливость и координацию.

### Сила
Использовать подходящие силовые упражнения и управляемую прогрессию нагрузки.

## Индивидуализация
- Цель не отменяет ограничений клиента.
- Место тренировки и оборудование влияют на выбор упражнений.
- Длительность занятия ограничивает общий объём.
- История тренировок влияет на стартовый уровень.
- Если информации недостаточно, сохранить черновик для проверки тренером.

## Контроль качества
Перед выдачей программы проверить:
1. соответствие цели;
2. соответствие уровню;
3. соответствие оборудованию;
4. соответствие ограничениям;
5. реалистичность длительности;
6. наличие прогрессии;
7. понятность инструкций.
