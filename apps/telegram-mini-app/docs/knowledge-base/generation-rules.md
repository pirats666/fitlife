# Правила генерации

## Pipeline
1. Получить профиль клиента.
2. Проверить безопасность и ограничения.
3. Определить цель.
4. Определить доступные дни, время и оборудование.
5. Выбрать структуру программы.
6. Выбрать паттерны движений.
7. Подобрать упражнения из Exercise Library.
8. Назначить объём, интенсивность и отдых.
9. Добавить правило прогрессии.
10. Проверить баланс и конфликт ограничений.
11. Сформировать программу.
12. Сохранить версию и rationale.

## Запреты
- не диагностировать;
- не назначать лечение;
- не использовать одно универсальное правило для всех;
- не считать боль обязательным признаком эффективной тренировки;
- не подменять источник уверенным утверждением.
